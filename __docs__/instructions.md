Some general notes from today's support session:


Clone the AIA26_Studio repository, and work within the repository.  
Only work inside your team's branch, coordinate with your teammates to avoid overwriting files.
Read the repository README document, you will find written instructions that match the setup we covered in Monday's workshop 01.
Test the default tools are working with your computer before developing new tools, if you are having trouble setting up your environment, post in this channel.
Define the inputs and outputs for both your Copilot overall and your grasshopper tools.  Swiftlet inputs are limited to string, number, integer, boolean, object (JSON), and array.  You will need to pass data to grasshopper in these formats, you will not be able to send a Polyline, Brep or other geometry.  If you need geometry you must construct it from one of these options.


Good luck y'all!
