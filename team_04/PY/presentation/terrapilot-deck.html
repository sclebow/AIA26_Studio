The Brain

How we break & understand a prompt

Every message flows through a 3-layer pipeline — most specific first, smartest fallback last.

⌨️
LAYER 1

Direct command

Exact instructions — “add 2 floors”, “rotate 30°”.

→
🧩
LAYER 2

Semantic intent

The LLM reads a feeling — “let in more daylight”, “it feels too boxy”.

→
🧠
LAYER 3

Reason Node

Decides the move + the WHY behind it, with confidence.

🔁

Two-tier fallback

Gemini → Cloudflare → keyword matching. It never dies on an API quota — the fallback is load-bearing.

🛡️

Hallucination guard

If a prompt matches no real operation, we reject it — never fake a change to look successful.

Depth

The hard problems we solved

🌀

Optimize keeps your edits

Optimizing a manipulated building preserves the twist + added floors — we carry the full floor-plate stack through every step, not a flat re-extrusion.

🗂️

Saved-shapes explorer

Browse saved designs → preview each in 3D → optimize the exact one you choose.

🛣️

Context-aware alignment

"Align facade to main road" rotates the building parallel to the real OSM road geometry — not a compass default.

All 6 environmental scorers run in dual mode — a geometry estimate and a real-data value — with a proxy/● live badge so you always know which is which.

Honest Status

What works — and what doesn't yet

✅ What works today
  • Plain-prompt shape generation, manipulation & per-wing floor editsTwist, courtyard, lengthen, align — all live
  • Multi-objective optimization with a true Pareto front8 named strategies, on-site 3D preview
  • Real environmental scoring — NASA + OpenStreetMapDual-mode proxy → real, never fabricated
  • Context-aware moves — "align to the road", "face the park"Uses real OSM road geometry
  • Save / preview / optimize saved versions end-to-endManipulation preserved through optimization
🚧 Current limitations
  • It's a scoring engine, not a full physics simulationFast, directional guidance — not a CFD / radiance solver
  • LLM intent depends on a free-tier quotaMitigated by a keyword fallback, but nuance can drop
  • Export is GeoJSON today; native Rhino / Revit needs the MCP bridgeIFC path is compatibility-level, not full BIM
  • Single building per site; massing is conceptualEarly-stage exploration, not construction documents
  • Context quality depends on OpenStreetMap coverageSparse-data areas → fewer real scores (shown as N/A)
We're deliberate about honesty: when data or a model isn't available, TerraPilot says so — it never invents a number to look finished.
